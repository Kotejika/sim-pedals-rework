# Цели и план Sim Pedals

## Решение по исходникам

После аудита **оставляем V2 как базовую архитектуру**. Полный rewrite не нужен на этом этапе: в V2 уже есть полезное разделение на драйвер ADS1220, обработку осей, ESB радио, USB HID, хранение настроек и PC-приложение.

Это не готовый релиз. Автор исходного V2 README прямо указывает, что проект собирался и проверялся на ПК, но на реальном железе не запускался. UF2 V4 у нас есть только как бинарники; исходников V4 нет. V2 нельзя называть V4.

Подробные находки: [SOURCE_AUDIT_RU.md](SOURCE_AUDIT_RU.md).

## Цель для iRacing

Сделать педали, которые помогают стабильно повторять точку и усилие торможения: низкий измеренный шум, предсказуемая калибровка, малые задержка и джиттер, отсутствие потери связи и корректное USB HID поведение.

Никакая прошивка сама по себе не гарантирует 5k iRating. Она должна убрать технические помехи и сделать управление повторяемым.

## Известное железо

- Тормоз: Mavin NA151, 200 кг, 4-проводный тензомост, номинально 2 мВ/В.
- АЦП: фиолетовый ADS1220, питание 3,3 В.
- ADS1220: SCLK D2, MOSI D3, MISO D4, CS D5, DRDY D6; E+ → AVDD, E− → AGND, S+ → AIN0, S− → AIN1; CLK → DGND.
- Газ и сцепление: SS49E Hall sensors, читаются внутренним SAADC nRF52840.
- Две Pro Micro-form-factor платы nRF52840: pedal node и USB hub.

Точную ревизию платы и полярность ключа питания датчиков на P0.13 проверяем по фактическому железу. Наличие 3,3 В непосредственно на ADS1220 не доказывает, что управление всей сенсорной шиной работает правильно.

## Что уже реализовано

- Nordic Enhanced ShockBurst (ESB), не BLE: PTX на педалях, PRX на Hub, 2 Мбит/с, auto-ACK/retry, 16-bit CRC.
- ADS1220: дифференциальный вход AIN0-AIN1, gain 128, continuous conversion, настройка на 1000 SPS и AVDD reference для ратиометрического измерения.
- SS49E через SAADC.
- Общая C-обработка осей: фильтр, min/max calibration, invert, deadzone, 11-точечная кривая.
- USB HID joystick и отдельный vendor HID интерфейс для конфигурации.
- Host-тесты математики осей на C и Python.

## Приоритеты исправлений

1. Уточнить P0.13 rail control и подтвердить pin map для фактической ревизии Pro Micro.
2. Улучшить ADS1220 driver: проверять возвраты всех SPI/GPIO вызовов, readback всех четырёх регистров, отдельные fault codes, счётчики DRDY и несколько последовательных ошибок до восстановления.
3. Пересмотреть ожидание DRDY и блокирующий main loop, чтобы временные задержки не превращались в ложный SENSOR ERROR и не срывали радиопередачу.
4. Исправить/проверить ESB ACK-payload queue/event ordering и добавить sequence-gap/loss/duplicate counters.
5. Согласовать USB live diagnostics между прошивкой Hub и Windows app.
6. Проверить поведение reconnect, failsafe, flash-save и sleep на реальном железе.
7. Только после этого выполнять сборку NCS 3.1.1 и hardware bring-up.

## Производительность измеряем, не декларируем

Не считаем настройку ADS 1000 SPS или USB interval 1 ms доказательством end-to-end 1 kHz. Отдельно измеряем ADC sample cadence, radio rate, USB report cadence, end-to-end latency, jitter, packet loss, noise, drift и brake repeatability. Фильтрацию настраиваем по данным, чтобы не добавлять ненужную задержку.

## Защитные правила релиза

- Оригинальные V4 UF2 храним как rollback.
- Никакую новую прошивку не называем проверенной на железе до испытаний на двух платах с реальными ADS1220, NA151 и SS49E.
- Не прошиваем изменённую прошивку до проверки питания сенсорной шины и failsafe.
